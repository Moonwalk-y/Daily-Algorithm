### 解法
有两种方法，一种是基础的二维dp数组，一种是一维dp数组，这次题解是二维
dp数组定义：`dp[i][j]`表示前i件物品里任选，在容量为j的背包中能装入的最大价值
dp数组初始化：j为0的话一个都不能装，就初始化成0。i为0表示只装入第一个物品，如果`weight[i] <= j`就是`value[i]`，否则就是0
遍历顺序：先遍历物品还是先遍历背包都可以，从前到后从左到右
递归公式：
如果`weight[i] >= j`,`dp[i][j] = max(dp[i-1][j],dp[i-1][j - weight[i]] + value[i])`
否则`dp[i][j] = dp[i-1][j]`
递推公式解释：`dp[i-1][j]`的意思是不选第i个物品的，前i个物品的最大价值；`dp[i-1][j - weight[i]] + value[i]`的意思是在没装入第i给物品前提下装入第i个物品。
### 代码
```C++
# include<iostream>
# include<vector>
using namespace std;
  
int main(){
    int M;int N;
    cin >> M >> N;
    vector<int> space(M);
    vector<int> value(M);
  
    for(int i = 0;i < M;i++){
        cin >> space[i];
    }
    for(int i = 0;i < M;i++){
        cin >> value[i];
    }
  
    vector<vector<int>> dp(M,vector<int>(N + 1,0));
  
    for(int i = 0;i <= N;i++){
        if(space[0] <= i) dp[0][i] = value[0];
        else dp[0][i] = 0;
    }
  
    for(int i = 1;i < M;i++){
        for(int j = 1;j <= N;j++){
            if(j - space[i] >= 0){
                dp[i][j] = max(dp[i - 1][j],dp[i - 1][j - space[i]] + value[i]);
            }else dp[i][j] = dp[i - 1][j];
        }
    }
  
    cout << dp[M-1][N] << endl;
}
```
